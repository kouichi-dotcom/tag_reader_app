## 要点（アプリ）

- 起動時: `GET /api/tag-readers/all` でキャッシュ（`EmployeeCache` と同パターン）
- 接続時: キャッシュ → なければ `GET ?address=` → なければ未登録表示
- 未登録: 接続後に登録ダイアログ（POST）
- 表示: `接続中: R-001 本社・検査用`（登録済み）/ `R-5000(16DBC3)（未登録）`
- 接続処理自体は従来どおり BLE 名 + address（`ConnectedDeviceStorage`）

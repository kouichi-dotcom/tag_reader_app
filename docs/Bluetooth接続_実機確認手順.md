# Bluetooth 接続安定化・実機確認手順

自動テストでは確認できない項目。Android / iPhone 実機と R-5000 で実施する。

## 前提

- アプリは staging（テスト）Flavor で起動
- 自動接続は行わない（接続画面の「接続」のみ）
- 通常切断で OS ペアリング削除はしない

## 確認項目

| # | 項目 | 手順 | 期待 |
|---|---|---|---|
| 1 | Android 接続・切断 | 接続 → 読取可能 → 切断 | 切断完了後、未接続表示。エラーなく再接続可 |
| 2 | iPhone 接続・切断 | 同上 | 同上 |
| 3 | A→B 引き継ぎ | スマホA接続→切断→スマホB接続 | ペアリング削除・電源再起動なしで B が接続できること（理想） |
| 4 | B→A 引き継ぎ | 同上を逆方向 | 同上 |
| 5 | 画面遷移で接続維持 | 接続後、ホーム／読取／設定へ移動 | 切断されない。読取可能 |
| 6 | バックグラウンド | 接続したままホームキー→復帰 | アプリから意図切断しない。OS切断時は未接続表示 |
| 7 | Bluetooth OFF | 接続中に BT OFF → ON | 接続切れ表示。手動で再接続 |
| 8 | R-5000 電源 OFF | 接続中に電源 OFF → ON | 接続切れ表示。手動で再接続 |
| 9 | 接続失敗後の再接続 | 範囲外などで失敗→近づいて再接続 | フラグ残りなく再試行できる |
| 10 | ペアリング削除なし繰り返し | 接続・切断を同一端末で 10 回以上 | 毎回 OS ペアリング削除が不要 |

## 複数端末切り替え（推奨）

スマホ A / B で接続↔切断を **最低 10 往復**。可能なら所要時間と成功率を記録する。

## ログ確認

デバッグコンソールの `[ReaderBT]` / `ReaderBT` タグ。

- `connect_start` / `connect_success` / `connect_failed` / `connect_timeout`
- `disconnect_start` / `disconnect_done`
- `link_lost` / `disconnected_event`

識別子は末尾数文字のみ（`device=名前(…xxxx)`）。

## 未実施時の扱い

実機未実施の項目は「成功」と報告しない。

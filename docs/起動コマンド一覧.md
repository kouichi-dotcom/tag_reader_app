# 起動コマンド一覧（アプリ / API）

開発でよく使う起動は次の **4 パターン**。Cursor に「Windows でローカル DB で起動して」などと頼むと、`.cursor/rules/startup.mdc` に従い同じコマンドを実行する。

| # | やりたいこと | 作業ディレクトリ | コマンド |
|---|--------------|------------------|----------|
| 1 | **アプリ（Windows）** | `C:\dev\tag_reader_app` | `flutter run -d windows` |
| 2 | **アプリ（Android 実機）** | `C:\dev\tag_reader_app` | `flutter run -d A142`（または `00067245O000580`） |
| 3 | **API（ローカル DB）** | `C:\dev\TagReaderApi` | `dotnet run --launch-profile http` |
| 4 | **API（本番 DB）** | `C:\dev\TagReaderApi` | `dotnet run --launch-profile http-production` |

API の URL はいずれも `http://localhost:5262`。接続先 DB は `ASPNETCORE_ENVIRONMENT`（launch profile）で切り替わる。

---

## 1. アプリ: Windows デスクトップ

詳細: [Windowsでの起動方法](Windowsでの起動方法.md)

```powershell
cd C:\dev\tag_reader_app
flutter pub get
flutter run -d windows
```

- RFID / Bluetooth タグリーダーは使えない（UI・API 疎通向け）
- API も使う場合は、先に **3 または 4** を起動する

---

## 2. アプリ: Android 実機

詳細: [タグリーダー実機テスト手順](タグリーダー実機テスト手順.md)

```powershell
cd C:\dev\tag_reader_app
flutter devices
flutter run -d A142
# または
# flutter run -d 00067245O000580
```

- 端末 ID: `A142` / `00067245O000580`（どちらで見えるかは接続・端末による）
- USB デバッグ ON・許可済みであること
- タグリーダーは端末側で Bluetooth ペアリング済みであること

---

## 3. API: ローカル DB

```powershell
cd C:\dev\TagReaderApi
dotnet run --launch-profile http
```

- `ASPNETCORE_ENVIRONMENT=Development`
- 接続先: `appsettings.Development.json`（例: `localhost\SQLEXPRESS` の `OOMIYADB`）
- 確認: `GET http://localhost:5262/api/environment` → `"environment":"Development"`

`dotnet run` のみ（プロファイル未指定）も Development（ローカル DB）になる。

---

## 4. API: 本番 DB

```powershell
cd C:\dev\TagReaderApi
dotnet run --launch-profile http-production
```

- `ASPNETCORE_ENVIRONMENT=Production`
- 接続先: `appsettings.Production.json`（社内本番 SQL Server）
- 確認: `GET http://localhost:5262/api/environment` → `"environment":"Production"`
- **書き込み系の操作は慎重に**（本番データを触る）

---

## よくある組み合わせ（自然言語 → やること）

| 言い方の例 | 起動するもの |
|------------|--------------|
| 「Windows でローカル DB で起動して」 | API **3** + アプリ **1** |
| 「Windows で本番 DB で起動して」 | API **4** + アプリ **1** |
| 「実機でローカル DB で起動して」 | API **3** + アプリ **2** |
| 「API だけローカルで」 | API **3** のみ |
| 「API を本番 DB で」 | API **4** のみ |

API とアプリは **別ターミナル** で長時間起動する（どちらかが落ちると疎通できない）。
